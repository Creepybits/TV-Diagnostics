# TV-Diagnostics
The Creepy Bits TV-Diagnostics hub. A custom-built dashboard to manage Android TV settings, view system stats, and optimize performance.  
___  

## TV-Diagnostics User Manual  
The Creepy Bits TV-Diagnostics hub is a specialized dashboard designed for Android TV. It provides a quick way to monitor system health and access buried system settings that are often hard to find with a standard TV remote.  

### 📊 Diagnostic Stats (Top Left)

The dashboard provides a real-time overview of your TV's current performance state:

* System: Identifies your specific TV model and manufacturer.
* RAM: Displays your currently used memory vs. total system capacity.
* Background Processes: Shows how many apps are currently active in the background.
* Android SDK: Lists your current software version and API level.

### 🛠️ Dashboard Controls  
**Run Quick Clean**  
This is the primary optimization tool. Clicking this will attempt to terminate non-essential background processes to free up system memory (RAM), helping to reduce interface lag on older TV hardware.  
___

### 🔗 System Shortcuts  
These buttons provide direct links to standard Android TV system menus that are usually hidden behind several layers of settings:  
**Dev Options:** Directly opens the "Developer Options" menu (useful for ADB debugging or changing animation scales).  
**Apps List:** Opens the master list of all installed applications to quickly clear caches or force-stop unresponsive apps.  
**Display:** Jump straight to resolution, refresh rate, and HDR settings.  
**Storage:** Provides a detailed breakdown of your TV’s internal drive usage and file management.
